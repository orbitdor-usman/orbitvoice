# Orbitvoice 1.2.1 — performance and packaging verification

Date: 2026-09-08. Windows x64, Electron 34.5.8, Next.js 15.5.25.

## Scope and implementation

Desktop behavior/performance and packaging only. No dashboard layout, CSS, logo, controls, supported language choices, models, optional AI integration, browser-recognition fallback, native input safety rules or website implementation was changed. An unrelated deletion of `website/public/downloads/.gitkeep` appeared during this work and was left untouched. The user's untracked `improve.md` was also left untouched. Nothing was published or pushed.

- Auto-stop remains three continuous seconds after speech, measured on 100ms PCM blocks. Tests cover resumed speech during natural pauses, quiet speech, initial silence and one-shot completion. No-speech timeout remains 12 seconds; maximum recording remains 60 seconds. The existing auto-stop setting remains available.
- Warm the selected model concurrently with microphone startup. Capture does not wait for model loading.
- Start speculative recognition after 600ms silence during short recordings, without stopping the microphone. Reuse only a completed transcription whose PCM samples exactly match the final recording. Never insert draft tokens; resumed speech requires a new result.
- Cancel stale preview decoding at token boundaries while retaining the loaded model. Yield the CPU worker between tokens so cancellation messages are processed. A compatibility adapter preserves normal stopping criteria/cache cleanup because the installed Transformers 4.2 Whisper implementation drops its public stopping-criteria argument.
- Retain streamed interim text and one final native insertion. Remove unnecessary full-buffer copies when trimming trailing silence. Clean up request timers, abort listeners and speculative work when a session ends.
- Use the CPU-only ONNX browser bundle and its one explicitly selected WASM/module pair. Remove generated unused JSEP, JSPI and Asyncify copies and the duplicate webpack-emitted runtime. Both pinned multilingual models remain unchanged.
- Keep ASAR, Windows x64-only packaging and all Electron locale resources. Exclude production source maps, debug/temp/test files and the duplicated in-ASAR native helper (the executable helper remains in `resources/native`). All production API dependencies and license notices remain.
- Use solid maximum-compression full-download NSIS packaging. Differential packaging was unused: this application checks GitHub releases and does not include a differential auto-updater. The update-checking feature is unchanged. The obsolete blockmap generated by the earlier test candidate was removed; this installer does not use it.

## Timing observations

Fixture: “The quick brown fox jumps over the lazy dog. Voice typing works without an API key.” Generated with Windows speech synthesis, with initial silence and five seconds of ending silence. Both final tests preserved the full fixture, including the natural pause between sentences.

| Model | Earlier 1.2.0 observation: silence stop to transcript | Final 1.2.1 observation: silence stop to transcript |
| --- | ---: | ---: |
| Base | approximately 8.5 seconds | approximately 3.4 seconds |
| Tiny / Fast | approximately 2.4 seconds | under 0.01 seconds; inference completed during the silence window |

These are individual synthetic-English measurements on this machine, not a controlled multi-run benchmark or a guarantee for other speech/languages/hardware. The earlier runs simulated the target adapter; the final runs used real native paste. The timings above exclude native clipboard-restoration completion, which intentionally waits about 1.5 seconds to let the target consume pasted data. Final UI success including native insertion/clipboard completion took about 5.0 seconds for Base and 1.6 seconds for Tiny after auto-stop. That clipboard safety delay was not removed.

Final Base job tracing confirmed a stale preview was cancelled and only the final matching-audio result was used. Tiny completed the final matching-audio candidate before the three-second silence window ended.

## Remaining release checks

The full install/upgrade/uninstall wizard, registry entries and shortcut creation have **not** been exercised. Windows Sandbox is unavailable, and upgrading would replace the user's currently running installed copy. Payload extraction/startup tests deliberately avoid changing that installation. Test the installer on a disposable Windows machine, or explicitly approve replacing the running installation, before calling installation fully validated.

No publisher signing certificate was supplied; the installer remains unsigned and Windows may warn. Live paid-AI calls, real microphone/noisy-room/accent accuracy, and native insertion into every third-party editor were not exhaustively tested. Existing fallbacks and native security checks were retained and covered by automated regressions. No app feature or offline model was removed to obtain these savings.
